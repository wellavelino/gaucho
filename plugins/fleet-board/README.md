# Fleet Board

Every agent on every machine: state, time in that state, repository and issue.
Press Enter to jump, Ctrl+R to refresh.

Bind `gaucho.fleet-board.open` to a key.

## Requirements

Needs `git`, `jq`, `fzf` and `gum` on the machine running Herdr. See
[Requirements](../../README.md#requirements) for install commands.
